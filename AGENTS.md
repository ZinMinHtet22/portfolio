## Output organization and push guidance

- Save generated documents, videos, and other outputs under `D:\Documents\Projects\<ProjectName>\Documents` or `...\Videos`, with the project name in each filename.
- Before any push, list files as "should push" and "should not push".
- Never push secrets, `.env` files, credentials, tokens, logs, caches, build output, temporary files, or personal documents.
- Ask for confirmation before pushing.
